# DataLens — Interactive Data Analysis Platform

A full-stack web application that lets you upload CSV datasets and perform interactive exploratory data analysis through a modern, professional dashboard.

## ✨ Features

- **CSV Upload** — Drag-and-drop or click to upload, with automatic validation and schema detection
- **Dataset Overview** — Row/column counts, missing values, duplicates, and data preview
- **Data Quality** — Per-column missing value analysis with progress bars, outlier detection (IQR method), and data type distribution
- **Auto Analysis** — Automatically generated histograms, bar charts, and time-series based on column types
- **Interactive Charts** — Build custom Bar, Line, Scatter, Pie, Histogram, and Box plots with axis/aggregation selection
- **Correlation Matrix** — Heatmap visualization with click-to-inspect strongest positive/negative correlations
- **Smart Insights** — 18+ auto-generated data-driven observations (never fabricated — all computed from your data)
- **Filters** — Dynamic column filters with type-appropriate operators (numeric ranges, categorical equality, etc.)
- **Export** — Download filtered CSV, analysis summary JSON, or chart screenshots
- **Dark/Light Mode** — Full theme toggle with localStorage persistence
- **Responsive Design** — Works on desktop, tablet, and mobile with collapsible sidebar

## 🚀 Getting Started

### Prerequisites

- **Python 3.10+** installed
- **Node.js 18+** and npm installed

### 1. Backend Setup

```bash
cd backend

# Install Python dependencies
pip install -r requirements.txt

# Start the API server
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

The backend API will be running at **http://localhost:8000**. You can visit http://localhost:8000/docs for the interactive API documentation (auto-generated by FastAPI).

### 2. Frontend Setup

```bash
cd frontend

# Install Node dependencies
npm install

# Start the development server
npm run dev
```

The frontend will be running at **http://localhost:5173** with hot module replacement.

### 3. Open the App

Visit **http://localhost:5173** in your browser. You can:

1. Click **"Try Sample Dataset"** to instantly load the bundled 200-row e-commerce dataset
2. Click **"Upload Dataset"** to upload your own CSV file
3. Explore all dashboard tabs: Overview → Data Quality → Explore → Correlations → Insights → Export

## 📊 Sample Dataset

The bundled `backend/data/sample.csv` contains 200 rows of realistic e-commerce sales data:

| Column | Type | Description |
|--------|------|-------------|
| OrderID | int | Sequential order identifier |
| Date | string | Order date (2024-01-01 to 2024-12-31) |
| Product | string | Product name (15 different products) |
| Category | string | Product category (Electronics, Accessories, Furniture, Lighting, Storage) |
| Region | string | Sales region (North, South, East, West) |
| Quantity | int | Quantity ordered (1–15) |
| UnitPrice | float | Unit price (9.99–499.99) |
| Revenue | float | Total revenue (Quantity × UnitPrice) |
| CustomerAge | float | Customer age (18–70), with ~5% missing |
| Rating | float | Product rating (1.0–5.0), with ~5% missing |

The dataset intentionally includes:
- **Missing values** (~20% in CustomerAge, Rating, Region) for data quality testing
- **Realistic patterns** — higher-priced items have lower quantities
- **Mixed column types** — numerical, categorical, and date-like columns

## 🔌 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/upload` | Upload a CSV file |
| POST | `/api/upload/sample` | Load the sample dataset |
| GET | `/api/overview/{id}` | Dataset overview statistics |
| GET | `/api/quality/{id}` | Column-level quality metrics |
| GET | `/api/explore/{id}` | Auto-generated chart data |
| POST | `/api/explore/{id}/custom` | Custom chart generation |
| GET | `/api/correlations/{id}` | Correlation matrix |
| GET | `/api/correlations/{id}/{col}` | Strongest correlations for a column |
| GET | `/api/insights/{id}` | Auto-generated insights |
| POST | `/api/filter/{id}` | Apply filters to dataset |
| GET | `/api/export/{id}/csv` | Download CSV |
| GET | `/api/export/{id}/summary` | Download analysis summary |

## 🧠 How It Works

1. **Upload** — CSV file is read with Pandas, validated, and stored in-memory with a UUID
2. **Classify** — Columns are auto-classified as numerical, categorical, or datetime
3. **Analyze** — Statistics, quality metrics, correlations, and insights are computed on-demand
4. **Visualize** — The frontend renders appropriate Recharts components based on data types
5. **Filter** — Users can add dynamic column filters; filtered results update overview and preview
6. **Export** — Download filtered CSV, JSON analysis summary, or chart screenshots

## 📝 Notes

- Datasets are stored **in-memory** (no database). Restarting the backend clears all data.
- Maximum file size: CSV files up to 1 million rows are supported.
- All insights are **computed from actual data** — nothing is fabricated or hardcoded.
